## Basic Reinforcement Learning

원본 출처: https://github.com/vmayoral/basic_reinforcement_learning

* 호환되지 않는 일부 코드들을 최신화했습니다. 최신 파이썬 버전에는 기존 코드가 작동하지 않는 것으로 확인됩니다.
* 일부 비효율적인 코드를 개선했습니다.
* pyinstaller를 통해 파이썬 없는 환경에서도 `dist/*.exe` 파일을 실행하여 구동되도록 만들었습니다. 이는 programs 폴더에서 확인할 수 있습니다.
* gym 라이브러리는 현재 유지보수가 종료되었습니다. 왠만해서는 이를 포크하여 업데이트한 gymnasium을 사용한 예제를 보시는 걸 추천합니다.
